Privacy Policy

# Privacy Policy — Backup Backup is a personal application used by the owner of a server to back up files to Google Drive. ## Google Drive access The application requests access to Google Drive so that it can upload, manage, and retrieve backup files belonging to the owner. The application does not sell, rent, or share Google user data with third parties. Google Drive data accessed by the application is used solely for the purpose of performing the requested backups. ## Data storage Backup files are stored in the owner's Google Drive account. The application does not operate a separate public database or sell any information obtained through Google APIs. ## Contact This application is maintained for personal use by the application owner.
